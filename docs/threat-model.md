# 위협 모델 (초안)

> M3 시점의 초안이다. 마일스톤이 진행될 때마다 "대응" 열을 채우고, M13에서 완성한다.
> 각 위협의 근거가 된 실제 사건은 [incidents.md](incidents.md)에 있다.

## 무엇을 지키나

| 자산 | 설명 |
|---|---|
| 엔드포인트의 비밀 | SSH 키, 클라우드 자격 증명, `.env`, 사내 문서 |
| 에이전트의 실행 권한 | 셸 명령, 파일 쓰기, 외부 요청. 에이전트가 사용자 권한으로 대신 실행한다 |
| 관제 데이터 | 중앙에 모이는 이벤트와 finding. 그 자체로 민감 정보다(누가 무엇을 했는지) |
| 정책 | 무엇을 막을지에 대한 규칙. 바뀌면 탐지가 무력화된다 |

## 누가 공격하나

| 공격자 | 가능한 일 | 예 |
|---|---|---|
| 외부 콘텐츠 작성자 | 에이전트가 읽는 텍스트를 조작한다 | 오염된 README, 웹 페이지, 이슈 본문의 프롬프트 인젝션 |
| 악성 확장 배포자 | 에이전트에 붙는 코드를 배포한다 | 악성 플러그인, tool poisoning이 된 MCP 서버 |
| 부주의한 내부 사용자 | 정책 밖 도구를 붙이거나 위험한 지시를 한다 | 미허가 MCP 서버 연결, 비밀값을 프롬프트에 붙여 넣기 |
| 악의적 사용자 | 정상 계정으로 에이전트를 공격 도구처럼 부린다 | 자격 증명 탐색, 대량 정찰 (GTG-1002) |
| 엔드포인트의 악성코드 | 설치된 에이전트를 안전장치 없이 대신 실행한다 | 권한 우회 옵션으로 CLI 실행 (Nx s1ngularity) |
| 침해된 엔드포인트 | 센서 토큰을 손에 넣고 중앙에 접근한다 | 가짜 이벤트 주입, 다른 장비 사칭 |

## 신뢰 경계

```
[외부 콘텐츠·MCP 서버] ──▶ [에이전트] ──▶ [센서] ══▶ [Control Plane] ──▶ [콘솔]
          ①                  ②             ③              ④
```

1. 에이전트가 읽는 모든 텍스트와 툴 설명은 신뢰하지 않는다.
2. 에이전트는 사용자 권한으로 실행되지만, 사용자의 의도대로 움직인다고 가정하지 않는다.
3. 센서와 중앙 사이의 네트워크는 신뢰하지 않는다. M12 전까지는 로컬 데모 네트워크로 한정한다.
4. 중앙은 센서가 보낸 내용을 검증 없이 믿지 않는다.

## 범위 밖

- **센서 자체를 끄거나 지우는 공격.** 엔드포인트의 관리자 권한을 가진 공격자는 센서를 우회할 수 있다.
  하트비트가 끊긴 장비를 콘솔에서 보이게 하는 정도까지만 다룬다(M7).
- **모델 자체의 취약점.** 탈옥이 되는지 여부가 아니라, 탈옥된 결과로 나오는 **행동**을 막는 것이 목표다.
- **에이전트를 거치지 않는 유출.** 사용자가 직접 파일을 복사하는 것은 DLP의 영역이다.
- **룰을 피하도록 다듬은 공격.** 패턴 룰은 변형에 약하다. 이 한계는 탐지율·오탐률 표(M13)에 그대로 적는다.
