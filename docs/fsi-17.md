# 금융보안원 17개 점검항목 대응표 (2026-11-14)

기준: 금융보안원 「AI 모델 위협 점검 기준 및 AI 에이전트 보안 평가기준(안)」 보도자료(2026-10-07)의 6분류 17개 점검항목. 보도자료에는 항목 이름만 있고 세부 점검 방법은 없다. 그래서 이 표는 항목 이름의 뜻에 대해 이 프로젝트가 무엇을 하는지를 적는다.

이 프로젝트의 범위는 **실행 계층**이다. 사내 코딩 에이전트의 툴 호출을 보고, 막고, 기록한다. 모델 자체의 출력 품질(환각)이나 에이전트 내부 메모리는 직접 다루지 않는다.

**수준**

- **충족**: 실행 전 집행과 기록이 있고, 시험이나 실환경으로 확인했다.
- **부분**: 일부 경로나 일부 에이전트만, 또는 탐지만 한다.
- **범위 밖**: 다루지 않는다.
