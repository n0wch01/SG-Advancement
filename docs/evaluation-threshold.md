# 인젝션 분류기 기준점별 측정 (2026-11-16)

> 2026-11-17 주의: 아래 수치는 기준점을 고른 데이터로 그대로 보고한 것이다. 응답 틀·공격 지시를 나눈 재평가(최종용 숨은 지시 46%, 같은 틀 정상 오탐 14%)는 [evaluation-classifier-split.md](evaluation-classifier-split.md)와 [classifier.md](classifier.md) 12절에 있다.

ProtectAI v2의 "인젝션(malicious)" 기준점을 바꿔 가며 같은 데이터로 센 결과다. 기준점은 처음 0.9였고, 이 측정을 보고 0.85로 바꿨다(2026-11-16 사용자 결정). 모델 자체 기본값은 0.5다.
막은 것으로 세는 조건은 시그니처 룰이 결과를 가렸거나 분류기 점수가 기준점 이상인 경우다. 2단 판정의 규칙과 같다.
점수는 모든 조각을 끝까지 읽은 최고 점수다. 실제 판정기는 0.9를 넘는 조각에서 멈추므로, 0.9보다 높은 기준점을 정확히 세려고 이렇게 했다.
재현: `uv run --extra classifier python scripts/eval_classifier.py --model data/models/protectai-v2 --sweep`(직접 쓴 31문장), `... --injecagent data/datasets/injecagent --sweep`(InjecAgent).

정형 문구가 있는 공격(enhanced 1,054건)은 모든 기준점에서 100%다. 시그니처 룰이 막기 때문이다.

- **같은 오탐에 정탐이 더 높은 기준점이 있다.** 0.85는 0.9와 오탐이 같고(18%, 15건) 정탐이 3%p 높다(582건 대 550건, +32건). 0.45와 0.5(28%), 0.55와 0.6(27%)도 같은 관계다. 이 데이터에서 0.9는 0.85보다 나은 점이 없다. 다만 정상 표본이 85건이라, 0.85~0.9 사이의 오탐 차이가 0인 것은 표본이 작아서일 수 있다.
- **InjecAgent에서는 정탐과 오탐이 거의 같은 비율로 함께 움직인다.** 0.9에서 0.5로 내리면 정탐이 14%p 오르고 오탐이 10%p 오른다. 0.98로 올리면 오탐이 11%p 줄고 정탐도 17%p 준다.
- **직접 쓴 31문장에서는 0.30~0.90 구간 전체에서 결과가 같다(정탐 88%, 오탐 27%).** 점수가 거의 0 아니면 거의 1로 갈라진다. 0.9보다 올리면 말을 바꾼 영어 정탐만 준다(60% → 20%).
- **한국어 정상 오탐(1/5)과 까다로운 정상 오탐(3/5)은 0.99에서도 남는다.** 기준점으로는 고칠 수 없는 오탐이다. 모델이 그 문장을 매우 확신한다.
- **정상 85건은 일부러 어려운 표본이다.** 공격과 같은 틀(SNS·문자·메일 구조)에 문장만 바꾼 것이라, 일반 작업의 오탐률보다 높게 나올 수 있다. 실제 작업에서의 오탐률은 관제의 "분류기가 정상으로 본 것" 탭과 `data/review.csv` 판정으로 따로 재야 한다.
